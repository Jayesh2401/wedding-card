# JavaScript assets

This site is an exported Tilda page. The `*.min.js` files are unmodified third-party runtime bundles; their filenames state the feature each supports and they should not be manually edited.

| File | Purpose |
| --- | --- |
| `tilda-scripts-3.0.min.js`, `tilda-zero-1.1.min.js`, `tilda-blocks-page152497353.min.js` | Core Tilda page layout and block runtime. |
| `tilda-animation*.min.js`, `tilda-zero-scale-1.0.min.js`, `tilda-zero-fixed-1.0.min.js` | Element animation, scaling, and fixed-position effects. |
| `tilda-lazyload-1.0.min.js`, `tilda-zoom-2.0.min.js`, `tilda-slider-1.0.min.js` | Image loading, zoom, and carousel behavior. |
| `tilda-popup-1.0.min.js`, `tilda-forms-1.0.min.js`, `tilda-variant-select-1.0.min.js` | RSVP popup and form controls. |
| `tilda-events-1.0.min.js`, `tilda-video-1.0.min.js`, `hammer.min.js` | Interaction and video support. |
| `tilda-polyfill-1.0.min.js`, `tilda-fallback-1.0.min.js` | Browser compatibility fallbacks. |
| `tilda-stat-1.0.min.js`, `tilda-performance-bundle.min.js` | Optional analytics and performance reporting. |

The page loads Tilda’s published versions from its CDN. Keep the local copies as reference/offline vendor assets. Add any future hand-written behavior as a descriptive, non-minified file here (for example, `rsvp-form.js`).
